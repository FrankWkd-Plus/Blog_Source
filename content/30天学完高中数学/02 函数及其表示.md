## 2.1 函数及其表示
### 1. 函数的概念

设集合 $A$ 是**非空的实数集**，对于 $A$ 中的任意实数 $x$，按照确定的**对应法则** $f$，都有**唯一**确定的实数值 $y$ 与它对应，则这种**对应关系**叫做**集合 $A$ 上的一个函数**，记作 $y = f(x), x \in A$。

其中，$x$ 叫做自变量，自变量的取值范围（数集 $A$）叫做这个函数的**定义域**；与 $x$ 的值相对应的 $y$ 值叫做**函数值**，函数值的集合 $\{y = f(x) \mid x \in A\}$ 叫做**函数的值域**。

函数 $y = f(x)$ 也常写作函数 $f$ 或函数 $f(x)$。

### 2. 函数的三种表示法

- **(1) 解析法：** 用代数式（或解析式）表示两个变量之间的函数对应关系的方法，如 $y = 2x - 6$。
	- **优点：** 一是简明、全面地概括了变量之间的关系；二是可以通过解析式求出任意一个自变量的值所对应的函数值。

- **(2) 图象法：** 把一个函数定义域内的每个自变量 $x$ 的值和它对应的函数值 $f(x)$ 构成的有序实数对 $(x, f(x))$ 作为点的坐标，所有这些点的集合就称为函数 $y = f(x)$ 的图象，即 $F = \{(x, y) \mid y = f(x), x \in A\}$。这种用“图形”表示函数的方法叫做图象法。
	- **优点：** 能够直观形象地表示与自变量的变化相对应的函数值的变化趋势，方便通过数形结合研究函数的相关性质。

- **(3) 列表法：** 列出自变量与对应函数值的表格来表达两个变量之间关系的方法。
	- **优点：** 不需要计算就可以直接得到与自变量的值相对应的函数值，对于由统计数据得到的函数关系，列表法很适用。

### 3. 同一函数

如果两个函数的**定义域相同**，并且**对应法则完全一致**，我们就称这两个函数是**同一函数**。

### 4. 区间的概念
> [!tip] 其中，“$+\infty$” 读作“正无穷大”，“$-\infty$” 读作“负无穷大”，“$\infty$” 符号不可单独出现！

> 设 $a, b \in \mathbb{R}$，且 $a < b$：

| **定义**                                 | **名称**       | **符号**         |
| -------------------------------------- | ------------ | -------------- |
| $\{x \mid a \leqslant x \leqslant b\}$ | **闭区间**      | $[a, b]$       |
| $\{x \mid a < x < b\}$                 | **开区间**      | $(a, b)$       |
| $\{x \mid a \leqslant x < b\}$         | **半开半闭区间**   | $[a, b)$       |
| $\{x \mid a < x \leqslant b\}$         | **半开半闭区间**   | $(a, b]$       |
| $\{x \mid x \geqslant a\}$             | **半开半闭区间**   | $[a, +\infty)$ |
| $\{x \mid x < b\}$                     | **开区间的特殊情况** | $(-\infty, b)$ |
> **注：** 实数 $a$ 与 $b$ 都叫做相应区间的端点。

### 5. 复合函数的概念

如果 $y$ 是 $u$ 的函数，记作 $y = f(u)$，$u$ 是 $x$ 的函数，记作 $u = g(x)$，且 $g(x)$ 的值域与 $f(u)$ 的定义域的**交集非空**，则通过 $u$ 确定了 $y$ 是 $x$ 的函数 $y = f[g(x)]$，这时 $y$ 叫做 $x$ 的**复合函数**。

其中 $u$ 叫做**中间变量**，$y = f(u)$ 叫做**外层函数**，$u = g(x)$ 叫做**内层函数**。

- **(1) 成立条件：** 只有当外层函数 $f(u)$ 的定义域与内层函数 $g(x)$ 的值域的交集非空时，才能构成复合函数 $f[g(x)]$。

- **(2) 符号辨析：** 理解函数符号 $f(x)$，及 $f[g(x)]$ 与 $g[f(x)]$ 的区别。

- **(3) 定义域：** 复合函数的定义域是由外层函数的定义域、内层函数的值域以及函数的定义域共同决定的。

## 2.2 映射与函数
### 1. 映射的概念

一般地，设 $A, B$ 是两个非空的集合，如果按某一个确定的对应关系 $f$，使对于 $A$ 中的**任意**一个元素 $x$，在集合 $B$ 中都有**唯一**确定的元素 $y$ 与之对应，那么就称对应关系 $f$ 为集合 $A$ 到集合 $B$ 的**映射**。映射 $f$ 也可记为：$f: A \to B$ 或 $x \to f(x)$。

此时，称 $y$ 是 $x$ 在映射 $f$ 的作用下的**象**，记作 $f(x)$；$x$ 称做 $y$ 的**原象**。其中 $A$ 叫做映射 $f$ 的**定义域**（函数定义域的推广），由所有的象 $f(x)$ 构成的集合叫做映射 $f$ 的**值域**，通常记作 $f(A)$。

### 2. 一一映射

如果 $f$ 是集合 $A$ 到集合 $B$ 的映射，并且对于集合 $B$ 中的任意一个元素，在集合 $A$ 中都有且只有一个原象，这时我们就说这两个集合的元素之间存在**一一对应关系**，并称这个映射叫做从集合 $A$ 到集合 $B$ 的**一一映射**。
