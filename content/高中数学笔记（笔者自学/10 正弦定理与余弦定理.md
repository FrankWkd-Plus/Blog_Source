## 10.1 正弦定理  
正弦定理：在 $\triangle ABC$ 中，有如下公式成立：  
- $\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}=2R$  
证明：  
![[attachments/Pasted image 20260220205937.png]]  
如图，作 $\triangle ABC$ 的外接圆，作 $CD\perp BC$ 交 $BC$ 于 $C$，连接 $BD$，$BD$ 即为直径 $2R$.  
$\because$ 同弧所对圆周角相等  
$\therefore$ $\angle A=\angle D$  
$\therefore \sin A=\sin D$  
$\because \angle C=90^{\circ}$  
$\therefore \sin D=\frac{a}{BD}=\frac{a}{2R}$  
$\therefore 2R=\frac{a}{\sin D}=\frac{a}{\sin A}$  
  
**扩展：**  
1. **边长表示角：**  
    - $a = 2R\sin A$  
    - $b = 2R\sin B$  
    - $c = 2R\sin C$  
2. **角表示边长：**  
    - $\sin A = \frac{a}{2R}$  
    - $\sin B = \frac{b}{2R}$  
    - $\sin C = \frac{c}{2R}$  
3. **比例关系：**  
    - $a : b : c = \sin A : \sin B : \sin C$  
4. **三角形面积公式：**  
    - $S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$  
  
## 10.2 余弦定理  
**基本形式**：  
- $c^2 = a^2 + b^2 - 2ab\cos C$  
- $b^2 = a^2 + c^2 - 2ac\cos B$  
- $a^2 = b^2 + c^2 - 2bc\cos A$  
**角变形形式（求角）**：  
- $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$  
- $\cos B = \frac{a^2 + c^2 - b^2}{2ac}$  
- $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$  
**证明：**  
- 以点 $C$ 为原点 $(0,0)$，边 $CB$ 落在 $x$ 轴正半轴上。  
- **设定顶点坐标：**  
    - $C(0, 0)$  
    - $B(a, 0)$  
    - $A(b\cos C, b\sin C)$ _(利用三角函数定义得出)_  
- **计算边长 $AB$：** 利用两点间距离公式：$$AB = c = \sqrt{(b\cos C - a)^2 + (b\sin C)^2}$$  
- **整理得出：**  
	$\begin{aligned} c^2 &= (b\cos C - a)^2 + (b\sin C)^2 \\ &= b^2\cos^2 C - 2ab\cos C + a^2 + b^2\sin^2 C \\ &= a^2 + b^2(\sin^2 C + \cos^2 C) - 2ab\cos C \\ &= a^2 + b^2 - 2ab\cos C \end{aligned}$  
  
## 10.3 正余弦定理在解三角形中的综合应用  
  
| **已知条件**                    | **应用定理**      | **一般解法**                                                    |     |  
| --------------------------- | ------------- | ----------------------------------------------------------- | --- |  
| **一边和两角**(如 $a, B, C$)      | 正弦定理          | 由 $A + B + C = \pi$，求角 $A$；由正弦定理求出 $b$ 与 $c$。               |     |  
| **两边和夹角**<br>(如 $a, b, C$)  | 余弦定理、正弦定理     | 由余弦定理求第三边 $c$；由正弦定理求出小边所对的角（此角一定是锐角）；再由 $A + B + C = \pi$。  |     |  
| **三边**($a, b, c$)           | 余弦定理          | 由余弦定理求出角 $A$、$B$；再由 $A + B + C = \pi$，求出角 $C$。              |     |  
| **两边和其中一边的对角**(如 $a, b, A$) | 正弦定理、<br>余弦定理 | 由正弦定理求出角 $B$；由 $A + B + C = \pi$，求出角 $C$；再利用正弦定理或余弦定理求 $c$。 |     |
